# DramaRecs v2

Static Node-built drama recommendations. Current MARQUEE design and self-hosted fonts are preserved. No accounts, runtime AI or application dependencies were added.

**Start with RELEASE-NOTES.md before deploying this repair release.** It disables ads, analytics and affiliate tracking pending proper integration/testing. No remote repository or deployment was changed.

## Run

```sh
node tools/release-build.mjs fixture
```

Or `npm run build:fixture`. For production: `npm run build:production`. Vercel runs `npm run build`, which includes validation, tests, generated-output/link checks and inventory. Node 20+ required.

`dist/` is generated output and is not included in the source ZIP. Serve it through HTTP, not file:// URLs, to test search and shelf fetching.

## Source map

- `data/dramas.json`: catalog editorial data; editorial episode/runtime values take precedence.
- `data/pages/*.json`: curated relationship lists and the single reason-aware pilot.
- `build.mjs`: static templates and metadata integration.
- `lib/data-quality.mjs`: testable identity/metadata/relationship safeguards.
- `src/core.js`: shared state, query handling, share parsing and catalog loading.
- `src/app.js`: browser interactions; `src/styles.css`: existing design plus targeted fixes.
- `tools/release-build.mjs`: actual checked deployment pipeline.
- `tests/*.test.mjs`: mandatory Node unit/DOM-mock tests.
- `tests/browser-smoke.mjs`: optional actual-browser suite, not executed in authoring sandbox.

## Handoff

`BACKLOG-STATUS.md` / `DramaRecs-action-plan.xlsx` cover DR-01 through DR-42 with remaining acceptance work. `PROJECT-STATE.json` distinguishes current facts from historical notes. `INVENTORY.json` and `EDITORIAL-REVIEW-QUEUE.json` are regenerated by the build. Older planning and audit narrative is preserved as historical reference, not current proof.

A filename such as `reply-1988.json` should not be assumed to exist: this supplied archive contains 101 recommendation lists, not the older notes' 152. Search labels distinguish Reviews from Recommendations.
