WHAT WAS FIXED
The old enrichment code made one search using query || title. Several uploaded catalog queries include search-engine-style qualifiers, for example Live 2018 Korean drama police and Law School Korean. A miss never retried canonical or native names.
The new helper retains the existing first search, adds a series-premiere-year API filter, and on no exact match retries canonical, Korean and supplied alias queries. It merges duplicate IDs and rejects ambiguous results. Exact name, premiere year and Korean-origin requirements remain intact. It never invents or auto-certifies an ID.
Later-season entries use the existing explicit seasonOf relationship to search their base series. Episode counts, display years and season endpoint enrichment remain unchanged. Missing or year-conflicting parent records do not override identity.
Production logs now list missing posters before enforcing the existing gate.

UNCHANGED
95% minimum poster coverage, poster/provider loss safeguards, director validator, editorial catalog, recommendation data, UI, fonts, static architecture, disabled advertising/analytics. No TMDB IDs were hardcoded or certified. No GitHub or Vercel changes were made by the assistant.
